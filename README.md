# vercel-todo-front

Vue 3 + Tailwind CSS で作成したTodoリストアプリケーション

## 機能

- タスクの追加
- タスクの完了/未完了の切り替え
- タスクの削除
- フィルター機能（すべて/未完了/完了）
- 残りタスク数の表示

## 技術スタック

- Vue 3（Composition API + script setup）
- Vite
- Tailwind CSS

## 開発

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```
